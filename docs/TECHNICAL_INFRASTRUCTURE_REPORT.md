## الملخص التنفيذي

منصة فحص العقوبات هي نظام متقدم مبني على تقنيات حديثة وموثوقة. تم تصميم البنية التقنية بعناية فائقة لضمان:

- **الأداء العالي**: معالجة آلاف الأسماء في دقائق
- **الموثوقية**: توفرية 99.9% على مدار السنة
- **القابلية للتوسع**: دعم النمو المستقبلي
- **الأمان**: حماية شاملة للبيانات الحساسة

النظام يلبي جميع المتطلبات التنظيمية والأمنية الدولية.

## المكونات الرئيسية

### 2.1 محرك البحث (Search Engine)

**الوظيفة الأساسية:**
معالجة استعلامات البحث وإرجاع النتائج الأكثر تطابقاً مع الاسم المبحوث عنه.

**آلية العمل:**

```
الاسم المدخل
    ↓
[تطبيع البيانات]
    ↓
[البحث السريع في الفهارس]
    ↓
[حساب درجة التطابق]
    ↓
[تصنيف النتائج]
    ↓
النتائج المرتبة
```

**التقنيات المستخدمة:**

| التقنية | الاستخدام |
|--------|----------|
| **Fuse.js** | البحث الضبابي (Fuzzy Search) |
| **Levenshtein Distance** | حساب درجة التشابه |
| **Regex** | معالجة النصوص والتطبيع |
| **Database Indexes** | تسريع البحث |

**معايير التطابق:**

```
درجة التطابق = (درجة التشابه × 0.6) + (عدد الكلمات المتطابقة × 0.4)

تصنيف النتيجة:
├── MATCH (تطابق): درجة >= 85% + >= 3 كلمات متطابقة
├── POSSIBLE_MATCH (تطابق محتمل): 60% <= درجة < 85% + >= 3 كلمات متطابقة
└── NO_MATCH (عدم تطابق): درجة < 60% أو < 3 كلمات متطابقة
```

### 2.2 معالج الباتش (Batch Processor)

**الوظيفة الأساسية:**
معالجة ملفات Excel الكبيرة التي تحتوي على آلاف الأسماء.

**مراحل المعالجة:**

```
مرحلة 1: تحميل الملف
├── التحقق من الصيغة
├── التحقق من الأعمدة
└── قراءة البيانات

مرحلة 2: التحضير
├── تحميل قوائم العقوبات في الذاكرة
├── تطبيع الأسماء
└── إعداد الفهارس

مرحلة 3: المعالجة المتوازية
├── تقسيم الأسماء إلى مجموعات
├── معالجة متعددة الخيوط
└── تتبع التقدم

مرحلة 4: حفظ النتائج
├── تخزين النتائج في قاعدة البيانات
├── حفظ درجات التطابق
└── تسجيل السجلات

مرحلة 5: إنشاء التقرير
├── جمع النتائج
├── إنشاء ملخص
└── إنتاج PDF
```

**معايير الأداء:**

| المقياس | القيمة |
|--------|--------|
| معالجة 1000 اسم | أقل من 5 دقائق |
| معالجة 10000 اسم | أقل من 30 دقيقة |
| استخدام الذاكرة | أقل من 2 GB |
| استخدام CPU | أقل من 80% |

## قاعدة البيانات

### 3.1 هيكل الجداول الرئيسية

#### جدول قوائم العقوبات (sanctionsRecords)

```sql
CREATE TABLE sanctionsRecords (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nameEn VARCHAR(255) NOT NULL,
  nameAr VARCHAR(255),
  entityType ENUM('Individual', 'Organisation', 'Vessel', 'Unspecified'),
  nationality VARCHAR(100),
  listingReason TEXT,
  actionTaken TEXT,
  dateAdded DATETIME,
  source VARCHAR(100),
  
  INDEX idx_nameEn (nameEn),
  INDEX idx_nameAr (nameAr),
  INDEX idx_entityType (entityType),
  INDEX idx_nationality (nationality)
);
```

**الحقول الرئيسية:**
- `nameEn`: الاسم بالإنجليزية
- `nameAr`: الاسم بالعربية
- `entityType`: نوع الكيان (فرد، منظمة، سفينة)
- `nationality`: الجنسية
- `listingReason`: سبب الإدراج
- `actionTaken`: الإجراءات المتخذة
- `source`: مصدر البيانات (UNSC, EU, OFAC, etc.)

#### جدول سجلات الفحص (screeningJobs)

```sql
CREATE TABLE screeningJobs (
  id INT PRIMARY KEY AUTO_INCREMENT,
  userId INT NOT NULL,
  fileName VARCHAR(255),
  status ENUM('PENDING', 'PROCESSING', 'COMPLETED', 'FAILED'),
  totalRecords INT,
  processedRecords INT,
  matchCount INT,
  possibleMatchCount INT,
  noMatchCount INT,
  createdAt DATETIME,
  completedAt DATETIME,
  
  FOREIGN KEY (userId) REFERENCES users(id),
  INDEX idx_userId (userId),
  INDEX idx_status (status),
  INDEX idx_createdAt (createdAt)
);
```

#### جدول نتائج الفحص (screeningResults)

```sql
CREATE TABLE screeningResults (
  id INT PRIMARY KEY AUTO_INCREMENT,
  jobId INT NOT NULL,
  inputName VARCHAR(255),
  matchedRecordId INT,
  status ENUM('MATCH', 'POSSIBLE_MATCH', 'NO_MATCH'),
  matchScore DECIMAL(5,2),
  matchedWordsCount INT,
  createdAt DATETIME,
  
  FOREIGN KEY (jobId) REFERENCES screeningJobs(id),
  FOREIGN KEY (matchedRecordId) REFERENCES sanctionsRecords(id),
  INDEX idx_jobId (jobId),
  INDEX idx_status (status),
  INDEX idx_matchScore (matchScore)
);
```

#### جدول المستخدمين (users)

```sql
CREATE TABLE users (
  id INT PRIMARY KEY AUTO_INCREMENT,
  email VARCHAR(255) UNIQUE NOT NULL,
  passwordHash VARCHAR(255) NOT NULL,
  fullName VARCHAR(255),
  role ENUM('admin', 'user', 'viewer'),
  organization VARCHAR(255),
  isActive BOOLEAN DEFAULT TRUE,
  lastLogin DATETIME,
  createdAt DATETIME,
  
  INDEX idx_email (email),
  INDEX idx_role (role)
);
```
