# دليل المسؤول لمنصة فحص العقوبات

## 1. مسؤوليات المسؤول

### 1.1 الإدارة اليومية
- مراقبة أداء النظام
- معالجة مشاكل المستخدمين
- التحقق من تحديثات البيانات

### 1.2 الإدارة الأسبوعية
- مراجعة سجلات التدقيق
- التحقق من استخدام النظام
- تقارير الأداء

### 1.3 الإدارة الشهرية
- تحديث قوائم العقوبات
- مراجعة الأمان
- تقارير الامتثال

## 2. إدارة المستخدمين

### 2.1 إضافة مستخدم جديد

**الخطوات**:
1. اذهب إلى Admin Dashboard
2. انقر على "Users"
3. انقر على "Add New User"
4. أدخل البيانات المطلوبة:
   - الاسم الكامل
   - البريد الإلكتروني
   - الدور (Admin, User, Viewer)
   - الجهة التابع لها
5. انقر على "Create"

**الأدوار المتاحة**:
- **Admin**: وصول كامل، إدارة المستخدمين، عرض السجلات
- **User**: فحص فردي وجماعي، تنزيل التقارير
- **Viewer**: عرض التقارير والنتائج فقط

### 2.2 تعديل بيانات المستخدم

1. اذهب إلى قائمة المستخدمين
2. انقر على المستخدم المراد تعديله
3. عدّل البيانات المطلوبة
4. انقر على "Save"

### 2.3 إعادة تعيين كلمة المرور

1. اذهب إلى قائمة المستخدمين
2. انقر على المستخدم
3. انقر على "Reset Password"
4. سيتم إرسال رابط إعادة التعيين للبريد الإلكتروني

### 2.4 تعطيل حساب المستخدم

1. اذهب إلى قائمة المستخدمين
2. انقر على المستخدم
3. انقر على "Disable Account"
4. سيتم تعطيل الحساب فوراً

## 3. إدارة البيانات

### 3.1 تحديث قوائم العقوبات

**التحديثات الدورية**:
- التحديثات تحدث تلقائياً حسب الجدول المحدد
- لا تحتاج إلى تدخل يدوي

**التحديث اليدوي**:
1. اذهب إلى Admin Dashboard
2. انقر على "Data Management"
3. انقر على "Update Sanctions Lists"
4. اختر المصادر المراد تحديثها
5. انقر على "Update"
6. انتظر انتهاء التحديث

### 3.2 استيراد البيانات

1. اذهب إلى Admin Dashboard
2. انقر على "Import Data"
3. اختر ملف البيانات (Excel أو CSV)
4. تحقق من البيانات
5. انقر على "Import"

### 3.3 تصدير البيانات

1. اذهب إلى Admin Dashboard
2. انقر على "Export Data"
3. اختر نوع البيانات المراد تصديرها
4. اختر الصيغة (Excel, CSV, PDF)
5. انقر على "Export"

### 3.4 حذف البيانات

**تحذير**: هذه العملية لا يمكن التراجع عنها

1. اذهب إلى Admin Dashboard
2. انقر على "Data Management"
3. انقر على "Delete Data"
4. اختر نوع البيانات
5. أدخل كلمة التأكيد
6. انقر على "Delete"

## 4. مراقبة الأداء

### 4.1 لوحة معلومات الأداء

تعرض المعلومات التالية:
- عدد عمليات البحث اليومية
- متوسط وقت البحث
- معدل الأخطاء
- استخدام الموارد (CPU, Memory, Disk)

### 4.2 تنبيهات الأداء

يتم إرسال تنبيهات عند:
- وقت البحث يتجاوز 1 ثانية
- معدل الأخطاء يتجاوز 1%
- استخدام الموارد يتجاوز 80%
- توقف النظام

### 4.3 التقارير

**التقارير اليومية**:
- عدد المستخدمين النشطين
- عدد عمليات البحث
- عدد المطابقات

**التقارير الأسبوعية**:
- ملخص الأنشطة
- تحليل الأداء
- المشاكل والحلول

**التقارير الشهرية**:
- تقرير شامل عن الاستخدام
- تحليل الاتجاهات
- توصيات التحسين

## 5. سجلات التدقيق

### 5.1 عرض السجلات

1. اذهب إلى Admin Dashboard
2. انقر على "Audit Logs"
3. ستظهر جميع العمليات المسجلة

### 5.2 البحث والتصفية

يمكنك البحث حسب:
- اسم المستخدم
- نوع العملية
- التاريخ والوقت
- النتيجة (نجاح/فشل)

### 5.3 تصدير السجلات

1. اختر السجلات المراد تصديرها
2. انقر على "Export"
3. اختر الصيغة (Excel, CSV, PDF)
4. انقر على "Download"

## 6. الأمان والنسخ الاحتياطية

### 6.1 النسخ الاحتياطية

**النسخ الاحتياطية التلقائية**:
- نسخة احتياطية يومية في الساعة 2 صباحاً
- نسخة احتياطية أسبوعية يوم الأحد

**النسخ الاحتياطية اليدوية**:
1. اذهب إلى Admin Dashboard
2. انقر على "Backup & Restore"
3. انقر على "Create Backup"
4. انتظر انتهاء العملية

### 6.2 استعادة من نسخة احتياطية

1. اذهب إلى Admin Dashboard
2. انقر على "Backup & Restore"
3. اختر النسخة الاحتياطية المراد استعادتها
4. انقر على "Restore"
5. أدخل كلمة التأكيد
6. انقر على "Confirm"

### 6.3 فحوصات الأمان

**الفحوصات الدورية**:
- فحص أسبوعي للثغرات الأمنية
- فحص شهري للامتثال
- فحص ربع سنوي للاختراق

**تقارير الأمان**:
1. اذهب إلى Admin Dashboard
2. انقر على "Security"
3. اختر نوع التقرير
4. اعرض النتائج والتوصيات

## 7. معالجة المشاكل

### 7.1 مشاكل شائعة

**المشكلة: النظام بطيء**
- تحقق من استخدام الموارد
- أعد تشغيل الخادم
- تحقق من قاعدة البيانات

**المشكلة: خطأ في البحث**
- تحقق من تحديثات البيانات
- أعد فهرسة قاعدة البيانات
- تحقق من السجلات

**المشكلة: مستخدم لا يستطيع تسجيل الدخول**
- تحقق من حالة الحساب
- أعد تعيين كلمة المرور
- تحقق من الصلاحيات

### 7.2 الدعم الفني

للمساعدة:
- تواصل مع فريق الدعم الفني
- أرسل تقرير مفصل عن المشكلة
- أرفق السجلات ذات الصلة

## 8. الصيانة الدورية

### 8.1 الصيانة الأسبوعية

- فحص صحة قاعدة البيانات
- تنظيف الملفات المؤقتة
- تحديث الفهارس

### 8.2 الصيانة الشهرية

- تحديث النظام
- تحديث المكتبات
- فحص الأمان

### 8.3 الصيانة ربع السنوية

- فحص شامل للنظام
- اختبار الاختراق
- تقييم الأداء

## 9. التقارير والإحصائيات

### 9.1 إنشاء تقرير مخصص

1. اذهب إلى Admin Dashboard
2. انقر على "Reports"
3. انقر على "Create Custom Report"
4. اختر المعايير:
   - نطاق التاريخ
   - نوع البيانات
   - المستخدمون
5. انقر على "Generate"
6. اعرض أو صدّر التقرير

### 9.2 الإحصائيات الرئيسية

- إجمالي عمليات البحث
- عدد المطابقات
- معدل النجاح
- المستخدمون النشطون
